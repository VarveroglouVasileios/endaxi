# Εντάξει

> **Είσαι εντάξει.**
> Compliance autopilot για τον Έλληνα ιδιοκτήτη βραχυχρόνιας μίσθωσης.

Ο host συνδέει το iCal του **μία φορά**. Από εκεί και πέρα το ΤΑΚΚ εκδίδεται μόνο του κάθε μήνα, με σωστή σειρά και αύξοντα αριθμό, και ο φάκελος για τον έλεγχο μένει πάντα έτοιμος.

---

## Γιατί δουλεύει χωρίς CSV, χωρίς API partnership

**Το ΤΑΚΚ είναι σταθερό ποσό ανά διανυκτέρευση** — δεν εξαρτάται από την τιμή της κράτησης, την προμήθεια ή το payout.

| Κατηγορία | Θερινή (Απρ–Οκτ) | Χειμερινή (Νοέ–Μαρ) |
|---|---|---|
| Ακίνητο βραχυχρόνιας μίσθωσης | €8/διαν. | €2/διαν. |
| Μονοκατοικία >80τμ / βίλα | €15/διαν. | €4/διαν. |

Άρα χρειαζόμαστε μόνο **ακίνητο + ημερομηνίες + διανυκτερεύσεις** — και αυτά τα δίνει δωρεάν το iCal που προσφέρουν Airbnb, Booking και VRBO σε κάθε host.

Το Airbnb API δεν είναι διαθέσιμο (μόνο πιστοποιημένοι PMS, αιτήσεις παγωμένες). Δεν το χρειαζόμαστε.

## Ξεκίνημα

```bash
cp .env.example .env
docker compose up -d      # τοπική Postgres στο :54329
pnpm install
pnpm test                 # 85 tests, μαζί με integration
pnpm demo                 # end-to-end: iCal → ΤΑΚΚ → PDF στο ./tmp
pnpm dev
pnpm inngest:dev          # σε δεύτερο terminal
```

> **Χρησιμοποίησε pnpm, όχι npm.** Ο resolver του npm σκάει σε αυτό το
> dependency tree με `Cannot read properties of null (reading 'edgesOut')`.
>
> Τα build scripts εγκρίνονται στο `pnpm-workspace.yaml` μέσω `allowBuilds`
> (στο pnpm 11 τα settings έφυγαν από το `package.json` και το
> `onlyBuiltDependencies` καταργήθηκε).

## Τα τρία σημεία που δεν επιτρέπεται να σπάσουν

### 1. Η αρίθμηση
Ο νόμος απαιτεί σειρά και αύξοντα αριθμό **χωρίς κενά**. Ο counter αυξάνεται μόνο μέσα σε transaction με `SELECT ... FOR UPDATE`. Ποτέ counter στη μνήμη.

### 2. Append-only
Εκδοθέν παραστατικό δεν γίνεται ποτέ `UPDATE`. Ακύρωση = **αντιλογιστικό έγγραφο**. Τα δεδομένα αντιγράφονται (snapshot) τη στιγμή της έκδοσης.

### 3. Ο μήνας απόδοσης
Καθορίζεται από την **αναχώρηση**, όχι την άφιξη. Check-out την 1η Μαΐου ανήκει στον **Μάιο**. Αυτό το λάθος ήδη κοστίζει πρόστιμα σε πραγματικούς hosts.

Και η δύσκολη περίπτωση που τα περισσότερα συστήματα χάνουν: διαμονή **30/10 → 02/11** έχει νύχτες σε **δύο εποχές** → 8 + 8 + 2 = **18€**, όχι 24€ ούτε 6€.

### 4. Το timezone στο iCal
Το node-ical παρσάρει το `DTSTART;VALUE=DATE:20260710` ως **τοπικά μεσάνυχτα**
(`2026-07-10T00:00:00+03:00`). Αν διαβάσεις UTC components παίρνεις **09/07** —
μία μέρα πίσω, σε κάθε ζώνη ανατολικά του UTC.

Στα όρια του μήνα αυτό αλλάζει και την **εποχή**: 01/11 (χειμερινή, 2€)
γλιστράει στις 31/10 (θερινή, 8€). Τετραπλάσιο ποσό, σιωπηλά.

Γι' αυτό τα tests τρέχουν με `TZ=Europe/Athens` — **σε UTC το bug δεν
αναπαράγεται και περνάει στην παραγωγή**.
